# Portfolio Pilot · 仓位助手

确定一次长期配置，平时按原计划定投，几个月后再回来核对持仓。工具安排复查日期，引导更新市值与本次新增资金，给出无需调整、新增资金纠偏或买卖调整的具体清单。纯静态运行，无需实时行情或每月打卡。

[打开工具](https://cznail.github.io/portfolio-pilot/)

## 低频复查

1. 确认长期计划后，首页显示下次复查日期、上次结论和持仓日期。默认每 6 个月检查，可改为 3、6、12 个月或指定日期，并记录自己的配置理由。
2. 到期点击“开始本次复查”，沿用原来的类别和比例，核对最新市值。资金期限或承受能力变化时，可重新评估配置。
3. 填写本次可追加资金，允许为零；过去几个月的定投已经包含在持仓市值中，不会自动累计月预算或重复加入。
4. 先看是否需要调整，再比较新增资金与买卖方案。买入、卖出按 1/10/100 元取整，剩余资金明确列在待投资余额。
5. 无需调整可直接结束；已按方案操作可保存估算结果，也可以填写实际市值。记录中保留调整前后快照、配置理由和下次日期。尚未操作可暂存，刷新或恢复备份后继续。

复查日期是使用安排，不预测届时必须交易。结束时按所选周期安排下一次；若记录后仍超出容忍范围，则提前到最多 3 个月后检查。持仓超过 30 天未核对时，需要重新核对后才能记录完成。只用新增资金回到范围的理论预算倍数放在展开说明中，不作为复查日期。

支持导出不含财务金额的 `.ics` 日历提醒、复制方案（剪贴板不可用时可手动复制）、打印独立的本次方案。提醒由导入后的日历应用负责，网页关闭时不在后台监控。示例分为正常复查、持仓偏离、额度受限三个场景，只在内存中运行。

最近保留 30 次复查，原有最近 20 笔执行记录继续兼容保存。平时不必回来更新或记录每月定投；长期定投清单可在首页展开查看。

## 定投计划

1. 填写已经扣除生活支出、备用金和预留现金后的**每月可定投金额**。工具不再从这笔钱里留现金。
2. 选择允许定投的资产类别，债券等类别可以不选。未选类别的目标与月投入均为零。
3. 回答资金期限、安全垫、亏损承受和下跌行为问题，或直接设置自己的比例。
4. 查看每类资产的比例与月投入，确认后保存为固定计划。月度金额分配到分，合计精确等于月预算。

固定定投金额不随持仓自动变化。修改预算、类别、比例先进入草稿，确认后才应用。每月预算不因记录一次再平衡而清零。

## 再平衡指导

独立入口始终显示当前与目标的比例、偏差和金额差，并判断是否超出容忍范围。容忍偏差取绝对阈值（默认 5 个百分点）与目标比例的 25% 中较小者；零目标类别使用绝对阈值。

- **后续定投逐步调回**：优先用新增资金补低配，列出本次各类投入以及暂停追加的类别，并与正常月投入比较。纠偏金额替代本月固定分配，不是在固定定投以外重复投入。
- **买卖一次调回**：逐类列出卖出、买入和调整后市值。金额参考未计费用、税费、限购与实际成交差异，完成买卖后核对真实持仓。
- 本次再平衡资金与每月预算独立，可一键使用月预算或不追加资金。
- 在价格不变、忽略限额及取整的假设下，估算只买入回到容忍范围所需的资金量下界和对应月预算数。这不是实际完成时间预测。持有目标为零的资产，追加只能稀释占比，无法将金额降为零。
- 只买入计划支持取整、剩余可买额度和预算守恒。未安排金额明确列出，不把它解释为重新预留生活现金。

## 风险与分散检查

规则版本 `2026-10-v2`。固定模板只给出投资资产内部比例，**不包含现金**：

| 模板     | 权益 | 黄金 | 债券 |
| -------- | ---: | ---: | ---: |
| 谨慎参考 |   0% |   0% | 100% |
| 稳健型   |  15% |   5% |  80% |
| 平衡型   |  45% |  10% |  45% |
| 成长型   |  70% |  10% |  20% |

结合能力与意愿取更谨慎的档位，再去掉未选类别并归一化。删去债券可能显著提高风险，因此重新检查实际比例，明确提示单一类别、权益集中、缺少债券、黄金集中及超出填写的亏损幅度。近期用款或生活安全垫不足也会提示暂缓投入。风险不匹配时需明确确认后采用，不能暗中加回未选资产。

区域偏好只调整美股与 A 股的权益内部分配；这两类均属权益，不能因有两个名称就认为充分分散。自定义类别缺少底层资产识别，会单独提醒。债券以分散、高质量债券为假设，黄金不能视为现金或债券等价物。

这些模板和提醒阈值由工具设定，并非经过验证的适当性测评或通用安全线，不保证收益或亏损上限。压力测试是同时下跌的静态情景，组合风险与包含备用金的全资产风险分别显示。方法参考 [Vanguard 关于期限、风险意愿与承担能力的说明](https://investor.vanguard.com/investor-resources-education/education/model-portfolio-allocation)。

## 持仓、执行与数据

- 按大类金额或总额与比例记录持仓，保留日期和估算标识。“待投资余额”仅指组合中尚未成交的零钱；生活现金在组合之外。
- 本月剩余可买额度在持仓页设置，记录纠偏执行后扣减，跨月手动核对。
- 记录纠偏执行后只清零本次资金，保留月预算；支持撤销和最近 20 笔记录。
- 演示在内存中运行，不覆盖真实数据。存储冲突或损坏时暂停保存。
- 当前格式与 localStorage 键继续使用第 4 版 `portfolio-pilot:portfolio:v4`。本次复查功能采用可选字段兼容扩展：原有第 4 版数据和备份保留预算、类别、策略及持仓，缺少的复查安排使用默认值，无需清空或重新配置。更早、无法识别的格式不会被猜测迁移或覆盖。JSON 包含复查日期、配置理由、历史快照和待完成方案。
- 导入先显示备份日期、组合市值、月预算、复查记录数和待完成状态；确认后在 `portfolio-pilot:before-restore:v4` 保留恢复前原始数据，可以预览并撤销恢复。无法保存恢复点时停止替换。导出时间和复查后备份提示可帮助低频使用者保留数据。
- 无云同步、行情接入或自动交易。清理浏览器数据会删除记录，建议定期导出备份。

## 开发

Node.js 24，React 19、TypeScript、Vite。

```sh
npm ci
npm run dev
npm test
npm run build
```

`src/domain/monthly.ts` 负责所选范围内的比例、风险提示与月投入；`strategy.ts` 负责问卷与确认；`planning.ts` 负责偏差、资金下界和执行；`rebalance.ts` 保持确定性的分币再平衡计算。定投与再平衡使用独立界面组件和预算状态。`review.ts` 负责自然月日期安排、复查状态与快照；`report.ts` 负责可复制/打印的调整清单。

测试覆盖预算守恒、类别排除、风险提示、资金下界、交易取整与现金尾差、自然月日期、过期持仓、兼容备份，以及完整复查、暂存恢复、实际结果、估算执行、复制降级、备份预览和撤销恢复的 DOM 流程。main 更新后，GitHub Actions 运行测试、类型检查和构建，再发布 GitHub Pages。

## 共享站点样式

配色、字体、钉子标志、全站导航、页脚与深浅色切换来自 [主页仓库的 site-ui](https://github.com/czNail/cznail.github.io/tree/main/packages/site-ui)。`vendor/site-ui` 是自动生成的副本，`site-ui.lock.json` 记录来源提交和 SHA-256 校验值。不要直接编辑副本。

- 更新：`node scripts/sync-site-ui.mjs --update`；核验：`npm run check:site-ui`。
- 构建和开发前自动核验副本并生成本站的主题脚本、图标；上线后不依赖跨站脚本加载。
- 每日工作流检查上游更新，通过本项目构建后提出升级 PR；仓库需要允许 GitHub Actions 创建 PR。
- 共享改版先在主页仓库运行四站桌面/手机、浅色/深色检查并审查截图；本项目保留自己的业务布局与数据格式。
