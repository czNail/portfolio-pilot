# Portfolio Pilot · 大类仓位助手

https://cznail.github.io/portfolio-pilot/

按美股、A 股、黄金、债券、现金管理整个组合，不需要股票或基金名称。

## 日常使用

1. 当前持仓可直接填写每类总金额，也可以选择“总额＋滑条”，只填组合总额，再拖动当前配比。
2. 目标配比通过滑条修改，其余类别按原比例联动，始终合计 100%。百分比也能精确输入。
3. 调整本次投入预算，自动得到各类买入金额、保留现金和安排后配比。
4. 风险页可拖动每类资产的假设跌幅和全资产预警线。
5. 本地自动保存，支持 JSON 备份及 CSV 计划导出。

基础类别直接提供；额外类别、月度上限和买入金额取整收在“更多选项”。初始目标和压力跌幅是可编辑示例，不构成配置建议。

## 资金和比例口径

- 上方资产类别组成参与配置的组合，现金也包含在组合占比中。
- 备用金是明确排除在目标配置之外的安全垫，仍参与全资产压力测算。已计入组合现金的金额不要再次填入备用金。
- **外部新增**：组合与全部资产增加预算，未买入部分成为组合现金。
- **使用组合现金**：全部资产和组合总额保持不变，仅使用指定预算范围内的现金买入。
- **从备用金转入**：全部资产不变，预算转入组合；未买入部分仍是组合现金，不会重复增加总资产。
- 计划只安排指定预算，不卖出已有资产。每类买入不得超过其投入后目标金额缺口，也受可选月度额度限制。
- 按 1、10 或 100 元的统一网格，在上述约束下用边际改善分配资金，最小化安排后的各类金额相对目标金额的平方偏差。余款留在现金。
- 月度额度应填可供本次计划使用的余额；不填写不限额，0 表示不追加。这里只给资产大类计划，不承诺某只基金可申购，也不计价格变动或交易费用。
- 风险测算对各类资产同时施加指定跌幅，以包含备用金的全部资产为分母；无法预测未来最大回撤。

## 旧版升级

- 新格式 `version: 2`，本地键 `portfolio-pilot:portfolio:v2`。
- 若没有新版记录，会读取旧键 `portfolio-pilot:portfolio:v1`，把基金市值按类别汇总。旧版本地键原样保留，不删除。
- 旧版单列存款迁为备用金，旧债券加入债券类别。目标按当前债券占比衔接原基金目标；旧目标未分配时参考当前资产占比衔接。请核对迁移提示和目标。
- 同类资产合并后的压力跌幅按市值加权，保持原情景金额；最多八个旧自定义类别仍能完整保留。
- 原基金级日限购、最低申购额和偏好不再参与大类计划。若需要限制，可按类别填写月度额度。
- 新旧 JSON 备份均可导入；新版记录损坏时暂停保存，不会自动用旧数据覆盖。
- “备份”页可以下载保留的旧版原始记录。

## 开发与部署

Node.js 24，React + TypeScript + Vite：

```sh
npm ci
npm run dev
npm test
npm run build
```

`npm run build` 执行严格 TypeScript 检查和生产构建。部署路径在 `vite.config.ts` 中配置为 `/portfolio-pilot/`。

GitHub Pages 的 Source 设为 **GitHub Actions**，推送 `main` 自动检查并发布。

没有后端、自动行情、账号同步或交易接口。数据在当前浏览器中；请定期备份。JSON 和 CSV 含资产信息，不要提交到仓库。同一 GitHub Pages 域名下的博客、主页和工具属于同一个浏览器源，路径不能形成严格的数据隔离。

测试覆盖滑条联动、金额守恒、三种资金来源、现金保留、月度额度、旧数据无损汇总、新旧备份、500 组随机组合与小规模穷举对照。
