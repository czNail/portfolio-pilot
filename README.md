# Portfolio Pilot · 仓位助手

面向长期定投的轻量资产配置工具。首次确定目标比例，以后更新持仓、输入预算，即可查看下一笔资金的安排。

[打开工具](https://cznail.github.io/portfolio-pilot/)

## 使用流程

1. **确定长期策略**：回答资金期限、备用金、亏损承受和下跌行为 4 个问题，查看建议比例、理由与压力情景，再明确确认。也可直接设置自己的目标。
2. **录入持仓**：按美股、A 股、黄金、债券、现金等大类填写市值，或用总额与比例估算。备用金单列，不参与目标配比。
3. **输入本次预算**：默认使用新增资金，优先补足低配类别。首页显示买入金额、留存现金、计划后的偏差与资金不足的说明。
4. **实际操作后记录**：按计划更新估算持仓，清零本次预算、扣除剩余可买额度，保存最近 20 笔执行记录。可撤销本次记录；有成交差异时直接核对实际市值。

## 交互与计算约定

- 未确认长期目标时不生成正式买入计划。修改策略和持仓先在草稿中进行，保存后才应用。
- 每类资产的偏离阈值，取“绝对偏差阈值”（默认 5 个百分点）和“目标比例的 25%”中较小者。零目标使用绝对阈值。提醒阈值可以调整。
- 默认只买入。高级选项支持使用组合现金、转入备用金、1/10/100 元取整及大类剩余可买额度。额度不会跨月自动重置。
- 新增资金不足以恢复配比时，明确保留偏差说明；含卖出的方案按目标金额提供比较参考，标出超限额项目，不直接写入执行记录。
- 更新市值时记录日期；按比例换算或按计划执行后的持仓标记为估算值。持仓日期未知或超过 30 天时提醒核对。
- 投资组合与含备用金的总资产分别计算压力损失，避免备用金掩盖组合风险。
- 演示数据在内存中运行，不覆盖已保存的数据。

## 配置规则

规则版本为 `2026-10-v1`，采用可解释的固定模板。资金期限与备用金约束风险承担能力；可接受亏损和下跌行为约束风险意愿，取更谨慎的一档。模板压力情景超过填写的亏损幅度时继续降低档位。

| 模板       | 权益 | 黄金 | 债券 | 现金 |
| ---------- | ---: | ---: | ---: | ---: |
| 流动性优先 |   0% |   0% |   0% | 100% |
| 稳健型     |  10% |   5% |  20% |  65% |
| 平衡型     |  35% |  10% |  30% |  25% |
| 成长型     |  65% |  10% |  20% |   5% |

区域偏好只调整权益内部的美股/A 股比例。模板使用本工具支持的资产范围，不代表全球市场组合。债券模板假设以分散的高质量债券为主，不能直接套用于高收益债或长久期债券。

这些比例是本工具的规则模板，并非经过验证的适当性测评，也不保证收益或亏损上限。压力测试是同时下跌的静态情景，不预测最大回撤。方法参考 [Vanguard 关于期限、风险意愿与承担能力的说明](https://investor.vanguard.com/investor-resources-education/education/model-portfolio-allocation)，具体模板与比例由本工具设定。

## 数据与隐私

使用当前浏览器的 localStorage，存储键为 `portfolio-pilot:portfolio:v3`，JSON 备份格式为第 3 版。新版独立运行，不读取或迁移旧版本数据，也不支持导入旧版本备份。没有云同步、行情接入或自动交易。清理浏览器数据会删除记录，请在重要调整后导出备份。

数据损坏或其他标签页修改数据时暂停保存，保留恢复入口。导入前校验金额、比例、策略、问卷和执行记录；当前版本备份可以完整恢复。

## 开发

Node.js 24，React 19、TypeScript、Vite。

```sh
npm ci
npm run dev
npm test
npm run build
```

- `src/domain/strategy.ts`：风险问卷、配置规则和策略确认。
- `src/domain/rebalance.ts`：分币计算、预算守恒、取整、限额与压力情景。
- `src/domain/planning.ts`：偏离判断、资金需求、执行记录和含卖出参考。
- `src/StrategyEditor.tsx`、`src/HoldingsEditor.tsx`：独立编辑草稿。
- `src/storage/`：版本化备份、校验、本地会话。
- `tests/`：计算不变量、问卷约束、执行原子性与 DOM 用户流程。

GitHub Actions 在 main 更新时运行测试、类型检查与构建，再发布到 GitHub Pages。Vite base 保持为 `/portfolio-pilot/`。
