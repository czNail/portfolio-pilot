# Portfolio Pilot · 仓位助手

React + TypeScript + Vite 的纯前端个人仓位工具，发布至：

https://cznail.github.io/portfolio-pilot/

## 功能

- 添加基金仅名称或代码必填，类别记住上次选择，市值可稍后直接在列表补填；支持连续添加。
- 限购、最低额、步长与权重均为折叠的可选设置；新基金默认不限购、1 元一档、同类均等分配。旧设置原样保留。
- 手动录入银行存款和债券资产；自定义最多 8 类资产、40 只基金。
- 基金类别目标比例、当前比例与偏离；安全资产单独统计。
- 修改持仓、目标和预算后自动更新只买入计划，结合每只基金的日限额、本月剩余申购额度、单次最低额、购买步长、同类别分配权重与暂停申购状态。
- 输出每只基金的金额和可执行日安排，保留无法分配的现金，导出 CSV 参考计划。
- 包含存款、债券的全资产情景压力测试，可比较当前与本次投入后。
- 本地自动保存、JSON 备份/恢复、损坏数据恢复下载、跨标签页冲突暂停保存。目标比例尚未合计 100% 时也可保存草稿、导出及恢复；计算买入计划前才要求合计 100%。
- 单条删除可撤销；全部清空和覆盖导入保留确认。
- 响应式布局、明暗主题、键盘可用的原生对话框。

初始页面没有真实持仓。默认目标比例与压力跌幅仅为可编辑的示例，不代表投资建议。演示模式使用虚构基金和数值，持续显示演示标记。

## 本地开发

Node.js 24：

```sh
npm ci
npm run dev
npm test
npm run build
```

`npm run build` 先进行严格 TypeScript 检查，再生成 `dist/`。`vite.config.ts` 设置 `base: '/portfolio-pilot/'`。

## 计算口径

1. 类别目标只在**基金组合**内计算，不含存款、债券。
2. 本月预算是**外部新增资金**，不会从已有存款扣除。计划后的总资产 = 当前总资产 + 全部预算；未分配部分计为新增现金。
3. 如希望从已有银行存款划转，应先在工具中手动扣减相应存款，再填入等额预算；避免重复统计。
4. 目标金额按“当前基金市值 + 全部预算”计算。只向目标金额仍有缺口的大类分配，不主动卖出。
5. 每一步比较可执行购买对大类平方金额缺口的单位改善，同类基金先按权重挑选下一笔，避免不同购买步长导致默认 1 元的基金挤占其他基金。整数步长、最低额和日限额构成离散约束，使用确定性启发式，不保证所有复杂约束下的全局最优。
6. 月度金额必须能拆为不超过可执行日数的有效购买；每次购买同时满足步长、最低额和日上限。不同金额组安排在不同执行日。
7. 未分配现金时，实际投入后比例仍可能偏离目标。未计费用、申购确认、交易时点价格变化、真实交易日历或限额临时变化。
8. 压力测试将各类资产的指定跌幅同时施加，损失率的分母为全部资产。静态情景不能预测未来最大回撤。

`src/domain/` 是独立于 React 的计算核心，金额分配内部使用整数分。预算上限 100 万元、购买步长最小 1 元，以限制计算成本。

## 数据与备份

- 本地键：`portfolio-pilot:portfolio:v1`；完整备份含应用名、版本、保存时间与配置。
- 导入限制为 1 MiB，严格验证结构、数字、比例、引用和标识唯一性，再确认替换。未知字段不会进入应用状态。
- 数值或结构无效时暂停自动保存，顶部明确提示；目标合计暂不等于 100% 则作为草稿正常保存。
- 本地数据损坏或检测到其他标签页修改时暂停保存，保留恢复下载与导出入口。
- 没有后端、账号、行情请求或自动交易；静态依赖不从第三方 CDN 加载。
- 同一 GitHub Pages 域名下的个人主页、博客与工具属于同一个浏览器源，路径不能严格隔离本地数据。
- 清理浏览器数据、隐私窗口或换设备都可能丢失持仓；请自行备份。JSON/CSV 含个人资产信息，不要提交到仓库。

## 部署

仓库 Settings → Pages → Source 选择 **GitHub Actions**。

推送 `main` 或手动运行 `Deploy Portfolio Pilot`，工作流执行 `npm ci`、`npm test`、`npm run build` 并发布 Pages。

## 验证

自动测试覆盖空组合、零预算、超配、限购、最低申购额、不可执行的月金额空隙、权重分配、分币余额、压力测试资金守恒、备份校验等；另有 400 组约束随机测试和小规模穷举对照。
